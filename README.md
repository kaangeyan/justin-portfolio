# Dr. Justin Sudhakar — Portfolio Website

Academic & EdTech portfolio website for Dr. Justin Sudhakar, bringing together teaching, academic research, digital learning, educational technology, examination operations, and academic content creation.

## Technology

No build step — plain HTML, CSS, and JavaScript.

The site is designed as a static website and requires no backend, database, or paid service.

## Run locally

1. Open the `justin-portfolio` folder in VS Code.
2. Use the **Live Server** extension (right-click `index.html` → "Open with Live Server"), or run a quick local server from the folder:

   ```text
   python3 -m http.server 8000
